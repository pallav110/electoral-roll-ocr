# Team handoff: electoral PDF pipeline

## 1. Run it locally

1. Install Docker Desktop and start Docker.
2. In this folder, run `cp .env.example .env`; change `ADMIN_TOKEN`.
3. Run `docker compose up --build -d`.
4. Open `http://localhost:8088` and sign in with username `admin` and the token from `.env`.
5. The included `sample-pdfs/demo-blank-13-pages.pdf` exercises the pipeline. Click **Discover PDFs now**. It should create one document, one session, two units and 26 **synthetic** records. The PDF contains blank pages; its records are generated by the mock adapter.
6. Use `docker compose logs -f worker beat web` for logs. Use `docker compose down` to stop without deleting data.

## 2. What is already built

- Hourly local-folder PDF discovery; SHA-256 identity prevents duplicate registration.
- PostgreSQL tables for documents, sessions, units, raw responses, metadata, voter records and events.
- Celery dispatch, page-range workers, automatic unit retry, heartbeat recovery, finalization and manual retry.
- Admin dashboard with progress, session history, raw JSON, normalized records, errors and events.
- A versioned extraction request/response shape and a mock implementation.

## 3. Integration work, in order

| Step | Change | Owner / file |
| --- | --- | --- |
| 1 | Agree on `POST /extract`: authentication, document access, page ranges, version, bilingual fields, source page/row IDs, confidence and structured errors. | Backend + extraction team; `app/extractor.py` |
| 2 | Set `EXTRACTOR_MODE=http`, `EXTRACTOR_URL`, `EXTRACTOR_API_KEY` and timeout. Adapt the request/auth/error mapping to the real service. Ensure its workers can read the PDF location or send PDF bytes/URLs instead. | Backend; `.env`, `app/extractor.py` |
| 3 | Map every confirmed electoral field into relational columns. Add fields to `ElectoralRecord` / `ElectoralDocumentMetadata` and `map_record` / `map_metadata`. Keep Hindi and English separate where queried. | Extraction + backend; `app/models.py`, `app/normalize.py` |
| 4 | Replace local-folder discovery and PDF access if the real document store is S3, Drive or another service. Prefer its stable document ID; fall back to content hash. Make sure worker and extractor can access the same object. | Backend; `app/workflow.py` `discover()` and `process_document_job()` |
| 5 | Add database migrations before changing existing schemas. `init_db.py` only creates missing tables. | Backend; new migration setup |
| 6 | Replace local Basic auth with organization auth and HTTPS before network exposure. Move database, Redis and API credentials to your secret store. | Deployment team; `app/main.py`, Compose/deployment config |
| 7 | Test real PDFs from each expected electoral format. Check row identity, Hindi/English mapping, totals, corrupted PDFs, extraction timeouts, partial pages, retries and worker loss. Tune `PAGES_PER_UNIT`, timeout and worker concurrency. | Extraction + backend + QA |

`rg 'TODO\(integration\)|TODO\(document-store\)' app` lists the deliberate integration points. Do not delete raw responses during normalization changes: they let you replay mappings without another extraction call.

## 4. Ready-for-real-data check

- `EXTRACTOR_MODE=http`; the mock adapter is no longer active.
- Real PDF produces the expected page count, units, raw responses and searchable Hindi/English rows.
- The same PDF is discovered once; changed content creates a new document.
- A transient failed unit retries independently; a normalization retry reuses a valid raw response.
- A failed document can create a new session while the previous session remains visible.
- The dashboard shows correct counts, progress, errors and retry history.
- Authentication, secrets, backup policy and schema migrations are in place for the intended environment.

## 5. Sharing the project

Zip the project source and `sample-pdfs/demo-blank-13-pages.pdf`. **Exclude `.env`**, which contains the local admin password; recipients should create their own from `.env.example`. Also exclude `__pycache__`, `.pytest_cache`, `.git` and Docker volumes. The helper `python3 package_for_team.py` writes a clean ZIP alongside this folder.
